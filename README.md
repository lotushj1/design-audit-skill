# Design Audit：交件前幫你檢查設計圖

## 這是什麼？

一個讓 AI 幫你做「交件前最後檢查」的技能包（Skill）。

設計圖做完要交出去之前，最怕的就是：有錯字沒看到、用了中國用語、廣告文案踩到法規、QR Code 放成舊活動的。這個 skill 就是請 AI 當你的最後一道防線，把這些問題全部抓出來。

它**不會**跟你聊這張圖好不好看。它只做一件事：把會出事的問題列出來，告訴你在哪裡、為什麼有問題、怎麼改。

## 它會幫你檢查什麼？

- **看得懂嗎**：第一眼能不能看出這張圖想講什麼、重點有沒有被搶走
- **讀得順嗎**：視線動線順不順、字會不會太小太擠、文字壓在圖上看不看得清楚
- **有沒有錯**：錯字、漏字、中國用語（例如「視頻」應該是「影片」）、明顯的資訊錯誤
- **會不會出事**：廣告文案有沒有誇大療效、絕對化用詞這類法規風險（台灣語境）
- **QR Code 對不對**：實際掃描解碼、打開連結，確認沒有放錯活動、沒有連到失效頁面
- **輸出乾不乾淨**：邊緣有沒有白邊、殘影、沒去乾淨的背景

每個問題都會附「參考改法」，文案問題直接給你改好的句子，不會只說「請調整語氣」。

## 怎麼用？

安裝後，把圖丟給 Claude，用平常說話的方式講就會觸發：

- 「幫我檢查這張圖能不能交付」
- 「這組輪播圖交件前幫我看一下」
- 「幫我看這張廣告圖有沒有錯字或廣告風險」
- 「檢查這張圖的 QR Code 有沒有放錯」

### 一次檢查一整個資料夾

要出貨的圖很多張時，直接指定資料夾：

- 「幫我檢查 `輸出檔` 資料夾裡所有的圖」

AI 會先列出找到幾張、一張一張檢查（標準不打折），最後給你一張總表：哪幾張可以直接交、哪幾張要修、哪幾張不能交。

## 檢查完會看到什麼？

每張圖會有：

1. **可交付性判斷**：可交付、建議修改後交付、不建議交付，三選一
2. **問題清單**：照嚴重程度排好，每條寫清楚位置、問題、為什麼、怎麼改
3. **文字風險提醒**：有錯字或廣告風險時，直接附上改好的參考文案
4. **QR Code 檢查結果**：解碼出的連結和實際內容對照

## 安裝

把 `SKILL.md` 和 `references/`、`scripts/` 資料夾放進：

```
~/.claude/skills/design-audit/
```

QR Code 檢查需要 Python 環境（會用到 `scripts/decode_qr.py`）。

## 提醒

- 廣告風險只會標「疑似有風險、建議確認」，不會下「違法」的結論。拿不準的還是要問專業人士。
- 它是來抓問題的，不會稱讚你的作品。想要改善建議請搭配 `design-improve`；想拆解別人的設計手法請用 `design-breakdown`。
