# 臺北資訊設計夜｜核定交付單

本案為虛構的學習活動。以下規格只適用於 Instagram 貼文「讀懂無障礙設計」。兩張圖是同一品項的前後版本。

- 交付一張 PNG，畫布 1080 × 1350 px，整張須不透明。
- 該貼文的活動時間為 2026/12/11（五）19:30，地點為臺北・北門共同工作室（虛構）。
- 圖片主旨為「讀懂無障礙設計」，副題為 WCAG 2.2 導讀。
- 唯一行動是閱讀 W3C 的 WCAG 2.2 網頁規範。掃碼和底部文字網址應抵達相同文件。核定落點 https://www.w3.org/TR/WCAG22/ 。可接受同一文件的 W3C 網域別名。
- 文字採臺灣繁體中文。主題與活動時間需可讀。
